Interactive Organization Chart for Vue 3

Organization Chart Vue3 is an open-source npm package for rendering hierarchical team and company structures. It supports collapsible nodes, TypeScript types, custom slots, and typed selection events.

npm install organization-chart-vue3

View the npm package · Read the documentation on GitHub

Vue 3 organization chart features

  • Interactive expand and collapse controls
  • TypeScript definitions for nodes, members, and events
  • Custom node-title and member slots
  • Vue 3.3.4 or later with no framework dependency beyond Vue
